# Electronic-Prescription-Validator

## Project Overview

Electronic Prescription Validator is a Python-based healthcare informatics project designed to check prescription completeness and identify missing prescription fields such as patient name, medication name, and dosage information.

This project demonstrates how simple healthcare technology tools can support medication safety, reduce prescription errors, and improve digital health workflows.

## Features

- Validates patient name
- Validates medication name
- Validates dosage information
- Detects incomplete prescriptions
- Provides validation results
- Simple command-line interface
- Educational healthcare informatics project

## Healthcare Impact

Prescription errors can affect patient safety and healthcare quality. Digital prescription validation tools can help identify missing or incomplete medication information before dispensing or clinical review.

This project supports the use of healthcare informatics and clinical decision support concepts to improve medication safety and reduce preventable errors.

## Technologies Used

- Python 3
- CSV sample data
- Healthcare informatics concepts
- Medication safety principles
